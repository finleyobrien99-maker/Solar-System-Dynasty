# Bundled fonts

Unmodified Google Fonts WOFF2 subsets of Exo 2 (400-700) and Orbitron (600-800).
Both carry the SIL Open Font License 1.1; full copyright notices and terms accompany these files.

Source stylesheet: https://fonts.googleapis.com/css2?family=Exo+2:wght@400..700&family=Orbitron:wght@600..800&display=swap

- exo-2-cyrillic-ext.woff2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYlK-4E4Q.woff2
- exo-2-cyrillic.woff2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYsK-4E4Q.woff2
- exo-2-vietnamese.woff2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYnK-4E4Q.woff2
- exo-2-latin-ext.woff2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYmK-4E4Q.woff2
- exo-2-latin.woff2: https://fonts.gstatic.com/s/exo2/v26/7cHmv4okm5zmbtYoK-4.woff2
- orbitron-latin.woff2: https://fonts.gstatic.com/s/orbitron/v35/yMJRMIlzdpvBhQQL_Qq7dy0.woff2

The application stylesheet imports these local files with the inline asset query, so web and single-file phone builds include the same fonts without a network request.
